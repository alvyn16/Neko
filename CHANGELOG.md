# Changelog

All notable user-facing changes to Neko are documented here.

## 0.3.5

- Added the browsable `FrenzyExists/wallpapers` source with folder categories, search, pagination, filtering, attribution, and resilient offline caching.
- Limited online preview work to visible gallery rows and improved preview responsiveness.
- Simplified preview actions to centered text-only controls.
- Added stricter provider URL, response-size, image-validation, and compatibility coverage.

## 0.3.4

- Refined the settings and pagination controls.
- Refreshed project documentation, contribution guidance, and issue templates.

## 0.3.2

- Previous release; see the [release notes](https://github.com/alvyn16/Neko/releases/tag/v0.3.2) for details.
